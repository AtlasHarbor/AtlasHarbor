# Go-to-Market compatibility

The former Go-to-Market Problem Space has been broadened and renamed **Propositions**.

- Canonical page: `/prop`
- Current documentation: [`docs/prop/README.md`](../prop/README.md)
- Legacy page: `/go-to-market` redirects to `/prop`
- Legacy API: `/api/go-to-market/*` remains mounted for compatibility
- Existing persistence: `atlas_problem_spaces.go_to_market` and `workspace_notes.resource_type = go_to_market_report` are retained so reports and publications do not break

Propositions supports internal work projects, company partnerships, sales pitches, investments, programs, policies, vendor decisions, products, brands, and market entries. Market research and launch economics are now optional modules rather than the required shape of every report.
